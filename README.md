# CoolGus

This is a simple Next.js project made to showcase a small, cosy, family-run sauna gus.

The sauna has been hand-built by the owner and is fully self-hosted. It offers a warm and welcoming experience in a compact setting. Visitors can enjoy:

- A handcrafted sauna cabin
- Two cold tubs — one of which is cooled down to 0°C
- Aromatic steam sessions using still bottles with scented oils, poured onto the heating stones for an immersive experience

The project aims to reflect the calm, personal atmosphere of the place, while remaining lightweight and user-friendly.

## Tech Stack

- [Next.js](https://nextjs.org/)  
- Hosted and maintained by the owner
